# Base alternativa React

O frontend em producao foi movido para `../backend/public/`: paginas HTML, JavaScript, CSS e assets originais. Ele e servido por `npm start` na pasta `backend`, sem build Vite. Os arquivos React restantes nesta pasta pertencem a base alternativa e nao sao a entrada do site publicado.

Painel web para visualizar agendamentos, faturamento e gerenciar bloqueios de horários.
